# 20260829 控制台进度日志

## 用户需求

在服务运行的控制台里打印当前转换任务的进展日志，方便挂机生成时直接观察终端。

## 小结

在 `src/server.ts` 的队列消费循环中增加控制台日志输出：

- `[转换]` 任务开始时打印文件名
- `[状态]` 打印 LLM 拆解等阶段性状态
- `[进度]` 段级合成进度，每 10 段打印一次、最后一段必打，避免整本书刷屏
- `[完成]` 打印产物文件名与大小（MB）
- `[失败]` 打印失败原因（stderr 输出，单任务失败不中断队列）
- `[队列]` 全部任务处理完后打印成功/失败汇总

日志与 WebUI 轮询进度互不影响，均为纯 console 输出。已通过 `npm run typecheck`。
